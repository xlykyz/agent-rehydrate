# Skill: log

向 `.agent/_state/logs/` 追加执行记录。

---

## 职责

记录项目执行历史——发生了什么、为什么、结果如何。日志是**客观的、不可变的**，只追加不修改。

---

## 文件结构

```
.agent/_state/logs/
└── development-log.md    ← 单文件，所有日志追加到此
```

## 日志格式

每条日志的结构：

```
[YYYY-MM-DD HH:mm] <操作类型> <简述>

<详细说明（可选）>

<关键结果>
```

**字段说明：**

| 字段 | 说明 | 必填 |
|------|------|------|
| `HH:mm` | 时间戳，24 小时制 | ✅ |
| `操作类型` | 如 `init`、`fetch`、`refactor`、`fix` 等 | ✅ |
| `简述` | 一句话说明做了什么 | ✅ |
| `详细说明` | 操作背景、上下文、决策理由 | 可选 |
| `关键结果` | 执行结果、产出文件、数据量等 | ✅ |

**示例：**

```
[14:30] init 创建项目状态目录结构

创建 .agent/_state/logs/、.agent/_state/wiki/ 目录，写入 _schema.md。

结果：.agent/_state/ 结构初始化完成
```

```
[15:45] fetch 拉取某股票日K数据

通过 tushare 接口拉取 000001.SZ 最近 90 天数据。

结果：拉取 62 条记录，其中 2026-05-20 数据为空（停牌）
```

---

## 追加规则

1. 在 `.agent/_state/logs/development-log.md` 末尾追加新日志
   - 文件不存在 → 创建文件，写入第一条日志
   - 文件已存在 → 在末尾追加
2. 每条日志之间空一行
3. **禁止**：修改或删除已有的日志条目

---

## 依赖

`init` — 依赖 `.agent/_state/logs/` 目录已存在。
