# State Schema

项目级状态重建协议的状态层格式规范。

---

## 目录结构

```
state/
├── _schema.md    ← 本文档
├── logs/         ← 执行历史
└── wiki/         ← 项目知识
```

## logs/

**用途**：记录每次执行的历史。发生了什么、为什么、结果如何。

**格式**：Markdown 文件，单文件 `development-log.md`。

**内容结构**：
- 每条日志以 `[YYYY-MM-DD HH:mm]` 开头
- 正文简要描述执行内容
- 关键结果附在末尾

---

## wiki/

**用途**：存放结构化项目知识。概念模型、术语定义、业务规则。

**格式**：Markdown 文件，建议用 `_index.md` 作为目录索引。

**内容结构**：
- 每个主题一个文件
- 文件名清晰体现主题
- 内容保持客观、稳定
